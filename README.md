# 🎪 EventGenie AI - AI-Powered Event Coordinator
> **Submitted for Google PromptWars - Challenge 5: Celebration & Event Planner**

EventGenie AI is an intelligent, interactive web app designed to take the stress out of organizing weddings, birthdays, and community gatherings. Built using Google Gemini API structured prompts, it auto-generates localized budget breakdowns, reverse-engineered milestone timelines, vendor outreach scripts, and tailored event themes in under 30 seconds.

## ✨ Core Features
1. **💰 Dynamic Budget Allocator:** Calculates category-specific costs based on event type and reserves a mandatory 10% contingency buffer.
2. **⏱️ Reverse-Engineered Milestone Timeline:** Computes key action items backwards from your event date.
3. **📋 Interactive Vendor Checklist:** Generates copy-paste outreach messages for caterers, venues, and decorators.
4. **💡 Personalized Creative Hub:** Brainstorms theme-matched icebreakers, decor ideas, and entertainment ideas.

## 🛠️ Tech Stack & AI Integration
- **Frontend:** Single-file HTML5, Tailwind CSS, Lucide Icons, Chart.js.
- **AI Core:** Google Gemini API (Gemini 1.5 Flash / Pro) with JSON structured outputs.
- **Tooling & Build:** Created and prototyped using Google Antigravity & AI Studio.
